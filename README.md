# Site Francielen Duarte

Página profissional da psicóloga clínica Francielen Duarte.

## Como rodar localmente

```bash
npm install
npm run dev
```

Depois acesse `http://127.0.0.1:3000`.

## Build de produção

```bash
npm run build
```

O projeto está configurado para exportação estática e publicação via GitHub Pages.

## Conteúdo e imagens

- Textos, telefone, CRP, redes sociais e caminhos de imagens ficam em `src/lib/site-data.ts`.
- Fotos e logotipos ficam em `public/images`.
